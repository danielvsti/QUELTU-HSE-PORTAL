# QUELTU HSE Portal

Portal web independiente para profesionales HSE de operaciones MINING.

## Propósito

- investigar tickets asignados;
- documentar análisis de causa raíz;
- evaluar riesgo inicial y residual;
- gestionar controles críticos, PNR y acciones;
- preparar informes y solicitar aprobación de cierre al Supervisor HSE.

Este frontend no es el Dashboard Ejecutivo ni la PWA del Resolutor. Consume
la API central de QUELTU en `https://api.queltu.com`.

## Despliegue

- Runtime: Static Site
- Publish directory: `.`
- Dominio productivo: `https://hse.queltu.com`
